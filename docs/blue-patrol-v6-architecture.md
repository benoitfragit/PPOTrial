# Historique d'architecture — notes de version V6

Ce document n'est plus une spécification de fonctionnement actif.

Le contrôleur actuel et les deux scénarios utilisent le moteur MAPPO P/N
décrit dans [BlueDefense](blue-defense-example.md). Les anciennes
implémentations d'entraînement spécifiques à deux Bleus ont été retirées.
Les noms de version conservés dans les checkpoints servent uniquement à
lire et migrer les anciens poids.

Consulter [MAPPO à effectifs variables](mappo-variable-teams.md)
pour le modèle et les mécanismes de reprise actuels.
